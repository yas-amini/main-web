# Linneaeas

This is a [Next.js](https://nextjs.org) project using TypeScript, Emotion for styling, and Storybook for component development.

## Getting Started

First, run the development server:

```bash
npm run dev


Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Features

- **Next.js 15** with TypeScript
- **Emotion** for styled components
- **Theme System** with dark/light mode support
- **Storybook** for component development and testing
- **React Icons** for icon components
- **Geist Font** for modern typography
- **ESLint** configuration for Next.js
- **Responsive Navigation** with mobile support

## Development Tools

### Storybook

To run Storybook for component development:

```bash
npm run storybook


This will start Storybook on port 6006. Open [http://localhost:6006](http://localhost:6006) to view your component library.

### Available Scripts

- `dev` - Runs the development server with Turbopack
- `build` - Builds the production application
- `start` - Starts the production server
- `lint` - Runs ESLint
- `storybook` - Starts Storybook development server
- `build-storybook` - Builds Storybook for production

## Project Structure

- `/app` - Main application code
  - `/layout` - Layout components
- `/.storybook` - Storybook configuration
- `/public` - Static assets
